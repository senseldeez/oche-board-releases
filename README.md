# Oche Board

Three-camera automatic scoring for steel-tip darts, for the Oche app. This repository holds the downloads only; get them from [Releases](../../releases).

| For | Download |
|---|---|
| Windows 10/11 (64-bit) | `Oche-Board-Setup-<version>.exe` |
| Linux desktop, PC | `Oche-Board-<version>-x86_64.AppImage` (make it executable, then open it) |
| Linux desktop, 64-bit ARM | `Oche-Board-<version>-aarch64.AppImage` |
| Headless Linux (Raspberry Pi OS 64-bit, Debian, Ubuntu, ...) | `install-oche-board.sh`: the one-line command is in each release's notes |

After installing, open Oche on your phone, find the board on the same Wi-Fi, and tap **Pair**: the board shows a 6-digit code to type in. Only paired phones can use it.

Free to use at home, in clubs and in pubs, with the official Oche apps only. See [LICENSE.txt](LICENSE.txt); the parts it is built from are listed in THIRD-PARTY-NOTICES.txt inside each download.
